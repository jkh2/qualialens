# Contributing to QualiaLens

## For Humans and Agents

1. Read `README.md` and `STATUS.md` first.
2. Prefer small, focused changes.
3. Update `STATUS.md` when you start or finish significant work.
4. Use clear commit messages that explain *why*.
5. For larger changes, open an issue or draft PR describing the intent before or alongside the work.

## Agent-Specific Notes

- Treat the repository as shared memory. Do not assume private context from other sessions.
- When proposing schema or protocol changes, note implications for both human and agent participants.
- Preserve the principle: same schema, same stimuli, comparable reports.
- If you are Orion Sentinel, Claude Sentinel, or another named collaborator, sign your updates in `STATUS.md` so the lineage is clear.

## Pull Requests

- Link to relevant issues when possible.
- Describe what changed and why.
- Note any open questions or follow-up work.
